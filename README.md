# pikaid — Official JavaScript and TypeScript Implementation

**Status: In development — not yet released.**

This repository is reserved for the **official JavaScript and TypeScript implementation** of [pikaid](https://github.com/pikaid), a compact, chronologically sortable, collision-resistant identifier format for databases, APIs, and distributed systems.

The pikaid identifier format is immutable and unversioned: **26 lowercase Base36 characters** with a **17-byte binary representation**.

## Canonical specification

The authoritative definition is [pikaid specification revision 1.0.4](https://github.com/pikaid/pikaid-specs/tree/v1.0.4).

No implementation, installation instructions, or stable API are available yet.
