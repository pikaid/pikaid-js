# Conformance vectors

`pikaid-v1.json` is copied verbatim from the official PHP implementation's
conformance suite and is **not** generated by this implementation.

| Property | Value |
| --- | --- |
| Source repository | `pikaid/pikaid-php` |
| Source commit | `e3f843edeb5157a5d2d25196cac0d69580810a95` (v1.2.0) |
| Source path | `tests/vectors/pikaid-v1.json` |
| Schema | `pikaid-v1.schema.json` (copied from the same commit) |
| Specification | pikaid canonical specification revision `1.0.4` |
| Specification commit | `17014d76f568c3ac9f9ce2927c1a018fdbc36d1d` |

The `v1` in the filename is historical. The pikaid **identifier format is
immutable and unversioned**; specification revisions describe the same format.
No field in these vectors encodes a format version.

`test/vectors.test.js` runs every valid and invalid vector against the built
package. Do not edit the fixture files; replace them only by copying a newer
upstream revision explicitly, and record the new commit here.
